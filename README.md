# ATM Machine - Python

A simple ATM System project made using Python.

## Features

- Create an account
- Generate account number
- PIN-based login
- Deposit money
- Withdraw money
- Check account balance
- View account details
- Store account data in an Excel file
- Automatically create the Excel file

## Technologies Used

- Python
- OpenPyXL
- Microsoft Excel
